# Om Gole — Portfolio

Personal portfolio website for **Om Gole**, focused on Machine Learning, AI, data analysis and computer vision.

## Tech Stack
- React
- Vite
- CSS
- Git & GitHub

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```
